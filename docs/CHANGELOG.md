2026-09-02 | v1.1.3 / 0014 | 修复：切换输出设备后音量监听失效 | Rust

- 根因：音量监听只绑定启动时的默认输出设备，切换蓝牙耳机/显示器后新设备上无监听

- 修复：在系统对象上监听 kAudioHardwarePropertyDefaultOutputDevice，默认设备变化时自动把音量监听迁到新设备（移旧注册新），并立即推送新设备当前音量
