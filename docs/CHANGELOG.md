2026-09-01 | v0.2.0 / 0003 | 新增：四种播放模式 + log 工作流 | 前端/脚本/文档

- 播放模式（控制栏按钮循环切换，localStorage 记忆上次选择，默认"播完下集"）：

  - 列表循环：播完切下一集，末尾回到第一集

  - 单集循环：播完重播本集

  - 播完暂停：播完本集停住

  - 播完下集：顺序播放，末尾停住

- log 工作流：log/ 目录 + 每日日志（YYYYMMDD.log），改动前写"进行"、完成后改"完成"；archive.sh 归档后自动写 log
