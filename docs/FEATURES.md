# playerWCY 产品功能总结

> 版本基线：v1.1.x（归档 0018，2026-09-02）
> 用途：产品功能全量清单，作为后续界面/体验优化的输入。

## 一、产品定位

macOS（Apple Silicon 原生）本地视频播放器：围绕"文件夹剧集"场景，核心是**进度记忆 + 键盘高效操作 + 轻量持久化**。

- 技术栈：Tauri 2（Rust + 原生 HTML/CSS/JS，无框架）
- 数据：SQLite（rusqlite bundled，静态编译进二进制）
- 体量：约 6.7MB

## 二、功能清单

### 1. 媒体库管理

| 功能 | 说明 |
|---|---|
| 打开文件夹 | 系统对话框选择目录，扫描一层内视频文件（mp4 / mov / m4v / webm / mkv / avi），按文件名排序 |
| 文件夹历史 | 打开过的文件夹永久保存（SQLite），重启后自动恢复；启动纯读库不扫磁盘 |
| 添加/刷新语义 | 再次打开同一文件夹 = 刷新：新文件入库，已有进度不覆盖，手动删除的记录不复活 |
| 分组树侧栏 | 每个文件夹一个分组（名称 + 视频数 + 折叠箭头），可收起/展开，折叠状态记忆 |
| 删除记录 | 右键视频条目删单条；右键组头删整个文件夹（级联删组内记录）；悬停勾选框多选（可跨文件夹）+ 底部"删除所选"操作条；均有确认弹窗；**仅删记录，不动磁盘文件** |
| 视频条目显示 | 文件名 + 播放百分比 + 迷你进度条，实时更新 |

### 2. 播放核心

| 功能 | 说明 |
|---|---|
| 播放/暂停 | 空格键或界面按钮；点击/双击当前播放项不重置进度 |
| 进度记忆续播 | 位置 >3 秒且 <98% 时自动续播；换源后元数据就绪时应用（防浏览器重置） |
| 自动保存 | 播放中每 5 秒节流保存；暂停/播完/切换/关窗立即保存（关窗 await 写入完成后才隐藏） |

### 3. 播放模式（四种，按钮循环切换，记忆选择）

| 模式 | 行为 |
|---|---|
| 播完下集（默认） | 当前文件夹内顺序连播，组末停住 |
| 列表循环 | 组内循环，末尾回到第一集 |
| 单集循环 | 播完重播本集 |
| 播完暂停 | 播完本集停住 |

连播范围一律限定**当前文件夹内**。

### 4. 播放控制

| 功能 | 说明 |
|---|---|
| 键盘快进/快退 | → 快进 5 秒、← 快退 5 秒；按住自动加速（5s → 8s → 12s → 20s 档位，120ms 节流） |
| 界面按钮 | 播放/暂停、快退 5s、快进 5s（线条风格图标） |
| 进度条 | 拖拽 + 点击跳转；拖动期间不被播放回写覆盖 |
| 倍速 | 预设 0.5 / 1 / 1.5 / 2 + 自定义输入 0.50–2.00（两位小数，如 1.65）；调整后记忆，换源自动重应用 |
| 音量 | 音量条 = 系统音量镜像（VirtualMasterVolume 读写 + 监听）；系统快捷键调节软件条实时跟随；输出设备切换自动重绑监听并同步新设备音量 |

### 5. 窗口与交互

| 功能 | 说明 |
|---|---|
| 关窗不退出 | 点 X 保存进度后隐藏窗口，应用驻留 Dock；点 Dock 图标恢复窗口（位置保持） |
| 侧栏收起按钮 | 视频区左上角悬浮按钮，点击收起/展开侧栏（宽度平滑过渡）；悬停放大、移开缩小；状态记忆；收起时自动清空多选 |
| 布局稳健 | 任意窗口尺寸下控制栏完整可见（空间不足收缩视频区） |
| 右键菜单 | 自绘菜单（删除记录），点击外部关闭 |

### 6. 视觉风格

- 深色主题（面板 #1d1d26 / 强调紫 #6f6fff）
- 全部图标线条风格 SVG（Lucide 风格，随主题变色）
- 应用图标：白底 + 黑色圆角边框 + 黑色线条播放三角

## 三、数据与工程

| 项 | 说明 |
|---|---|
| 数据库 | `~/Library/Application Support/com.wcy.playerwcy/data.db`，两张表（videos / folders），旧数据自动迁移 |
| 归档 | 每次编译产物入 `20260901-playerWCY-archive/`，四位序号-日期-产品名自增 |
| 开发日志 | `log/YYYYMMDD.log`，改动前"进行"、完成后改"完成" |
| 自动化测试 | cargo test 7 项（数据层 roundtrip / clamp / 文件夹生命周期 / 批量删除 / 扫描排序与错误路径） |
| 开源 | GitHub 公开仓库，MIT，Copyright (c) 2026 alanwangcanyi |

## 四、已知限制

| 限制 | 说明 |
|---|---|
| 视频格式 | mp4/mov/m4v/webm 完整支持；mkv 内 H.264 多数可播；HEVC / avi 老编码可能无法播放（macOS WebKit 解码能力所限，后续可评估 ffmpeg 软解） |
| 文件移动 | 纯读库启动，文件被移动后记录仍在但播放失败（符合"除非手动删除"的设计；后续可加失效提示） |
| dmg 打包 | 本开发环境沙盒限制 hdiutil，仅 .app 可自动产出（终端手动执行可出 dmg） |
| 排序 | 文件名小写字典序（ep10 < ep2），非数字感知自然排序 |
