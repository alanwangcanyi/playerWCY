# 开发计划（PLAN）

> **用途**：每次新需求开工前，必须先在此建立该需求的任务计划表；每完成一项立即把状态改为"已完成"。AI 与人都以此文件跟踪进度。
>
> **状态定义**：
> - `未开始`：尚未动工
> - `进行中`：正在实施（同时只能有一项进行中，避免并行打架）
> - `已完成`：实现+验证+归档全部完成
> - `已取消`：决定不做（保留记录，注明原因）
>
> **规则**：计划先行是强制流程（见《编程agents规则.md》第一节）；一版完成后该版计划表移入底部"历史计划"。
